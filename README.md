# DreamAtlas

DreamAtlas is an open-source, privacy-first dream journal with optional trusted and pseudonymous sharing.

## Implemented foundation

- owner-scoped private entries;
- optimistic revisions;
- stable redacted sharing copies;
- transparent personal theme counts;
- minimum-publisher suppression for public themes;
- request validation, initial schema and tests.

DreamAtlas is for reflection and creativity. It does not diagnose conditions or assign universal meanings.

## Run locally

```sh
npm install
npm test
npm run dev
```

Open http://localhost:3103. See [the roadmap](docs/ROADMAP.md) for planned work.
